ABOUT THE PROJECT

Built, tested, and explained.

JordanHeritageVision compares EfficientNetB0, ResNet101, VGG16, and InceptionV3 trained to recognize six Jordanian landmarks. The full study includes data cleaning, error analysis, Grad-CAM, and a model efficiency benchmark.

Privacy-first demo

Images are processed locally using WebAssembly. No image is uploaded to a prediction server. The model and runtime are downloaded when needed.
